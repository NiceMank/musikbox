# Aether v1

Branche de travail pour le nouveau lecteur.

## Lecteur
- Lecture / pause / suivant / précédent
- Seek, volume, mute
- Aléatoire, répéter (off / tout / un)
- File d'attente
- Égaliseur 3 bandes + vitesse
- Minuteur de sommeil
- Mode Dream (visuel plein écran)
- Raccourcis : Espace, flèches, D

## Recherche & radio
- Recherche iTunes (extraits 30 s)
- Suggestions en direct
- Tendances
- Radio live (Radio Browser)

## Bibliothèque locale
- Favoris, enregistrements, playlists, historique (Memory lane)
- Playlists intelligentes (plus écoutés, récents)

Le serveur Python historique (`server.py`) reste sur `main`.
